# SKYPHANTOMS · Место пилота

Кабина SKYPHANTOMS с интерактивным листом персонажа: приборы и механизмы нарисованы в SVG, а за стеклом — шесть секторов локальной круговой панорамы. Внешние шрифты, библиотеки и подключение к интернету не требуются.

Приборная доска скомпонована заново: все функциональные панели находятся внутри металлической рамки и не перекрываются. Характеристики собраны в два ряда, схема самолёта — в центре, диагностика — над приборами, самолёт и форсаж — внизу. Неиспользуемый КИ‑13 удалён. Капот выполнен из матового окрашенного металла: плавная объёмная форма, мягкое отражение неба, тонкие швы съёмных панелей, утопленные крепления, жалюзи охлаждения и небольшие следы масла и сколы. Дизельпанковый стиль капота и ручки управления сохранён; бумага на планшете слегка состарена и испачкана. Прицел повторяет фото: четыре концентрических кольца, двенадцать спиц и тяжёлое железное крепление.

Внизу перед пилотом — двуручный авиационный штурвал: металлическая дуга с бакелитовыми хватами, кнопкой и гашеткой, изогнутая колонка, шарнир и складчатый кожаный чехол у пола. Основание полностью видно. Потяните штурвал мышью или пальцем; после выбора клавишей Tab работают стрелки. При отпускании он плавно возвращается в центр. Пробел или двойной щелчок выравнивает горизонт.

При развороте по курсу примерно через каждые 60° меняется окружение: **0° — небесные города; 60° — открытое небо с самолётами и солнцем; 120° — грозовой фронт; 180° — безоблачное море; 240° — самолёт на взлётной полосе; 300° — ангар напротив механиков**. Между секторами есть мягкие переходы. Солнце и луна нарисованы внутри дальнего фона. На солнце появляются засветка стекла и оптические отражения; ночью они отключены.

Нажмите на центральную табличку имени, чтобы вписать своего пилота. Книга **«Полёты для чайников»** в кожаном кармашке заменяет декоративные приборы «Топливо» и «Воздух» и открывает памятку с лором, ресурсами и таблицей попаданий D10. Центральный экран без наведения показывает самолёт сверху: целые узлы зелёные, повреждённые жёлтые, узлы с 1 STR или разрушенные красные. При наведении на прибор или его выборе клавиатурой экран временно показывает характеристику.

## Пробная версия на GitHub Pages

Репозиторий: [SAAJava/SkyphantomsSite](https://github.com/SAAJava/SkyphantomsSite). Файлы сайта уже находятся в корне ветки `master`. Для первого запуска используется штатная публикация GitHub Pages из этой ветки. Отдельный workflow и сборка не нужны.

Пробная версия запущена пользователем: [открыть SKYPHANTOMS](https://saajava.github.io/SkyphantomsSite/). Следующие локальные изменения появятся там после коммита и отправки в `master`.

Первое включение:

1. Откройте [Settings → Pages](https://github.com/SAAJava/SkyphantomsSite/settings/pages).
2. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
3. Ниже в **Branch** выберите **master**, папку **/(root)** и нажмите **Save**.
4. После успешного запуска ссылка появится в **Settings → Pages** и в результате задания публикации. При стандартном адресе GitHub Pages ожидается `https://saajava.github.io/SkyphantomsSite/`.

Для первого включения дополнительный push не требуется: HTML, CSS, JS и фоны уже отправлены пользователем. После включения следующие изменения в `master` публикуются автоматически. В [Actions](https://github.com/SAAJava/SkyphantomsSite/actions) можно проверить стандартный запуск **pages build and deployment**. Дополнительные ключи или секреты не нужны. Для общедоступного репозитория GitHub Pages доступен на бесплатном тарифе; для закрытого доступность зависит от тарифа. [Официальная инструкция GitHub](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

Локальный пустой файл `.nojekyll` можно отправить со следующими изменениями, чтобы GitHub копировал статические файлы без обработки Jekyll. Текущая HTML-страница без front matter и PNG-фоны работают также при стандартной публикации. При публикации из корня дополнительные файлы репозитория тоже могут попасть на сайт.

На сайте каждый игрок заполняет собственный лист: данные сохраняются в его браузере. Общего сервера персонажей пока нет. Сохранения с `127.0.0.1`, `localhost` или `file:///` автоматически на адрес GitHub Pages не переносятся.

Папки `artifacts`, `tmp` и `.idea` уже попали в первый локальный коммит. `.gitignore` исключает новые файлы этих папок, но уже отслеживаемые файлы сам не убирает. При необходимости исключить их из следующих версий репозитория, сохранив на диске:

```powershell
git rm -r --cached --ignore-unmatch -- artifacts tmp .idea
```

## Как открыть завтра

Проект находится в папке **`D:\site`**. Это обычная HTML-страница с локальным сохранением данных. Устанавливать Java, Maven, Node.js или библиотеки для игры не нужно. Для способа запуска ниже нужен Python; на этом компьютере он уже использовался для запуска страницы.

1. Откройте **PowerShell** или **Терминал Windows**.
2. Вставьте эти две строки и нажмите Enter:

```powershell
cd D:\site
python -m http.server 8765 --bind 127.0.0.1
```

3. Оставьте это окно открытым и откройте в браузере **http://127.0.0.1:8765/**.
4. Если после правок видна старая версия, нажмите **Ctrl+F5**.

Сохраните этот адрес в закладки. После перезагрузки компьютера сначала снова выполните команды, затем откройте закладку. Просто закладка сама сервер не запускает. Интернет для работы страницы не нужен.

Чтобы закончить работу сервера, нажмите **Ctrl+C** в его окне или закройте окно терминала. Закрытие сервера не удаляет сохранённого персонажа.

### Где сохраняется персонаж

Имя, характеристики, здоровье, удача, навыки, оборудование, живучесть узлов, форсажи и режим освещения автоматически сохраняются **в браузере**. Файл персонажа в папке проекта не создаётся.

Чтобы завтра увидеть свои значения:

- Открывайте страницу в том же браузере и том же профиле, где заполняли лист.
- Используйте тот же адрес: **http://127.0.0.1:8765/**. У `localhost`, другого порта и открытия через `file:///` отдельные хранилища.
- Используйте обычное окно браузера: сохранение в приватном или временном профиле может исчезнуть после его закрытия.
- Не очищайте данные этого сайта и не нажимайте «Сбросить», если хотите сохранить персонажа.

Копирование папки `D:\site` переносит саму страницу, но не сохранения браузера. Экспорт и импорт персонажа пока не реализованы. Количество кубиков запоминается, а история последних бросков хранится только в текущем сеансе страницы.

### Открытие без сервера

Можно открыть папку `D:\site` в Проводнике и дважды нажать **`index.html`**. Рядом должны лежать `cockpit.css`, `cockpit.js`, `dice.js` и папка `assets` с панорамой.

Это работает без Python и интернета, но сохранения будут относиться к файловому адресу. Для продолжения персонажа, заполненного по адресу `http://127.0.0.1:8765/`, используйте запуск через PowerShell выше.

### Если не открывается

| Что произошло | Что сделать |
| --- | --- |
| Браузер пишет, что соединение не установлено | Запустите сервер командами выше и оставьте терминал открытым. |
| Терминал сообщает, что порт 8765 уже занят | Сначала откройте http://127.0.0.1:8765/ — возможно, сервер уже работает. Если там другая страница, проверьте ранее открытое окно сервера. |
| Команда `python` не найдена | Попробуйте `py -3 -m http.server 8765 --bind 127.0.0.1` из папки `D:\site` или откройте `index.html` напрямую. |
| Вместо кабины показан список чужих файлов | Сервер запущен из другой папки. Остановите его через Ctrl+C и выполните обе команды заново. |
| Страница открылась, но персонаж выглядит новым | Проверьте браузер, профиль и точный адрес. Данные другого адреса не подхватываются автоматически. |
| После изменения файлов оформление осталось прежним | Нажмите Ctrl+F5. |

## Как пользоваться кабиной

Тяните стрелки мышью или пальцем, нажимайте на нужное деление шкалы или выделите прибор клавишей Tab и используйте стрелки клавиатуры. Home и End устанавливают крайние значения. Стрелка движется плавно, после отпускания фиксируется на делении.

За стеклом — круговая панорама из шести окружений. Изначально показан одобренный фон военного технофэнтези с парящими городами, цеппелинами и авианосцами над облачной бездной. Дальше по курсу идут ясное небо, гроза, море, взлётная полоса и ангар с механиками. Все иллюстрации хранятся в `assets`; предусмотрен запасной фон из SVG при их отсутствии. Удерживайте ручку управления влево или вправо для разворота на 360°: после полного круга возвращается та же часть панорамы. Название окружения отображается рядом с курсом. В ясном секторе солнце вызывает засветку и блики; в грозовом видны дождь и редкие вспышки. Крен в повороте ограничен 9°. Вверх и вниз меняют тангаж. При отпускании ручка и крен возвращаются в центр, направление сохраняется. Двойной щелчок по ручке, пробел или «Выровнять» возвращают горизонт. Работают клавиши со стрелками. Управление видом не меняет характеристики персонажа.

Винт нарисован заново: металлические лопасти с закрученным профилем, светлыми законцовками и потёртостями. Ступица установлена в опорный узел на капоте. В покое лопасти непрозрачны, при вращении прозрачность составляет 40% (непрозрачность 60%). Тумблер **«ВИНТ»** слева от имени включает и останавливает анимацию; выбор запоминается и не меняет STR двигателя. Явно включённый винт вращается также при настройке уменьшения движения; остальные анимации её учитывают.

Металлический тумблер **«ДЕНЬ / НОЧЬ»** справа от имени переключает освещение. В ясном секторе дневная иллюстрация заменяется ночной с луной и звёздами; остальные секторы, корпус и металл получают ночное освещение. Работают нажатие, Enter и пробел. Приборы, дисплеи и сигнальные лампы светятся отдельно от корпусов. Режим сохраняется.

Через кнопку «Лётная книжка» можно редактировать имя, биографию, характеристики, текущее здоровье, очки удачи и заметки. Значения сохраняются в браузере на этом устройстве; у файлового адреса и локального сервера хранилища могут отличаться.

Справа находятся два рычага, похожие на ручки газа: **Здоровье** и **Удача**. Тяните рукоятки вверх или вниз либо нажимайте на деления. После Tab используйте стрелки, Home (0) и End (максимум). Шкалы автоматически соответствуют текущим максимумам HP и удачи; значения сохраняются, синхронизируются с лётной книжкой и индикаторами. Красная лампа включается при 2 HP и ниже.

Внутри кабины слева находится бумажный планшет: изначально 10 строк, кнопка «+» добавляет по одной до 25. Размер планшета не меняется: видны 10 строк, остальные доступны прокруткой списка. Введите произвольное название и установите бонус горизонтальным бегунком от 0 до +5. Число строк, названия и бонусы сохраняются вместе с персонажем. Кнопка ↗ разворачивает планшет для редактирования. На узких экранах планшет показывается компактно и открывается нажатием на ↗.

Слева внизу приборной доски находится панель самолёта со скоростью, манёвренностью, бронёй и счётчиком занятых слотов. Нажатие открывает бортовой паспорт. Начальные параметры — скорость 3, манёвренность 4, броня 0. Изначально показаны три модуля: носовая пушка с уроном 2, форсаж на 2 применения и дымовая завеса. **Лимит слотов по типу самолёта** редактируется в паспорте; по умолчанию он равен 10. Можно задать больше или меньше. Кнопка «+ Добавить слот» добавляет одну строку до выбранного лимита. Слот считается занятым, если заполнено название или эффект. Уменьшение лимита не удаляет оборудование и добавленные пустые строки: превышение отмечается подсказкой, добавление блокируется. Лимит и строки сохраняются вместе с персонажем. В старых сохранениях без явного числа строк пустые строки после последнего заполненного слота скрываются до добавления кнопкой «+».

Пять верхних кнопок отслеживают живучесть из карточки самолёта: Оперение / Крылья (D10 1–3), Двигатель / Мотор (4), Топливная система (5), Вооружение / Пушки (6–8), Кабина / Управление (9–10). У каждого узла собственные броня, максимум и текущий STR. В паспорте максимум STR задаётся отдельно от 1 до 10; базовый максимум равен Техпределу + 3 (по умолчанию 8). Нажатие снимает 1 STR; при нуле следующий клик восстанавливает узел до его максимума. Красные ячейки означают потерянный STR. Если броня больше нуля, под STR появляется вторая синяя полоса. Она показывает рейтинг брони и не расходуется при нажатиях на STR. Статусы и штрафы при STR 1–2 показываются по карточке, но не меняют введённые характеристики автоматически. При изменении максимума целые узлы остаются целыми, повреждённые сохраняют текущий STR с ограничением новым максимумом.

Вместо верхних левых часов установлен счётчик форсажей с тремя вращающимися цифровыми барабанами, до 999. Нажатие на цифры расходует один форсаж, при нуле счётчик остаётся на 000. Кнопка ↻ восстанавливает весь запас. Начальный запас берётся из числового эффекта модуля «Форсаж» (по умолчанию 2); запас и остаток можно менять в паспорте самолёта. Все ресурсы сохраняются. При уменьшении движения цифры обновляются без прокрутки.

Кнопка «Броски D10» открывает отдельное окно в стиле лётной книжки. Выберите от 1 до 5 десятигранников и нажмите «Бросить». Анимация показывает бросок и остановку кубиков, затем выводятся значения 1–10 и сумма. Количество кубиков запоминается, последние пять бросков отображаются в текущем сеансе. При закрытии окна во время анимации уже определённый результат сохраняется в истории. Настройка уменьшения движения в браузере отключает вращение кубиков.

| Характеристика | Прибор |
| --- | --- |
| Подвижность | Указатель скорости |
| Реакция | Вариометр |
| Внимательность | Курсовой прибор |
| Стойкость | Авиагоризонт |
| Атлетизм | Тахометр |
| Харизма | Радиосвязь |
| Жизненность | Давление масла |
| Удача | Высотомер |

Диапазон характеристик — 1–5, бюджет — 24 очка. Здоровье рассчитывается как Жизненность × 2, максимум очков удачи равен Удаче. Изменение характеристик пересчитывает максимумы ресурсов; уже потраченные ресурсы не восстанавливаются при увеличении максимума. Если ресурс был полным, он остаётся полным после изменения максимума.

Красные ячейки вертикального индикатора показывают потерянную долю максимального HP и заполняются снизу вверх. При потере половины здоровья красными становятся 5 из 10 ячеек. Большая красная лампа «Здоровье» находится на центральной панели и загорается при 2 HP и ниже, независимо от максимума. Например, при максимуме 10 HP лампа выключена на 3 HP и включена на 2, 1 и 0 HP.

Для копии самой страницы сохраните вместе `index.html`, `cockpit.css`, `cockpit.js`, `dice.js` и папку `assets`. Документацию тоже стоит перенести. Папки `artifacts`, `tmp` и оставшиеся файлы Java/Maven для запуска кабины не нужны.

## Продолжение работы в другом чате

Прикрепите `CHAT_CONTEXT.txt` или вставьте его содержимое. Если новый чат имеет доступ к этой папке, можно написать:

> Продолжаем проект SKYPHANTOMS в D:\site. Прочитай D:\site\CHAT_CONTEXT.txt и D:\site\README.md, затем внеси следующие изменения: …

Само наличие текстового файла не даёт новому чату доступ к компьютеру. Если доступа к `D:\site` у него нет, дополнительно передайте основные файлы страницы и папку `assets`.
